01 Overview

The Milkwave scripting system lets you automate the Milkwave Remote, which controls the Milkwave Visualizer (a MilkDrop-based music visualizer). Scripts are plain text files containing lines of commands that are executed sequentially or on-demand.

With scripts you can:

  • Send text messages that appear as animated overlays on the visualizer
  • Switch presets, change fonts, colors, and styles
  • Control playback timing with BPM-synced autoplay
  • Trigger sprites and keycodes
  • Adjust rendering settings (intensity, hue, quality, etc.)
  • Run external programs
  • Chain any combination of the above on a single line

The default script file is script-default.txt in the Milkwave base directory. You can load other files by right-clicking the "From File" label on the Message tab in the Remote window.

02 File Format

Script files are plain text (.txt) with one instruction per line:

# Lines starting with # are comments (ignored by the parser)
# Blank lines create delays in autoplay

BPM=120|BEATS=8|STYLE=Style A|Welcome to Milkwave!
NEXT
This text is sent as a message

SIZE=60|BOOM
STOP

Rules

  • Comments — lines starting with # are ignored
  • Blank lines — create one beat-interval delay during autoplay
  • Pipe separator — use | to chain multiple commands on one line
  • Plain text — anything that isn't a recognized command is sent as a message to the visualizer
  • Case — command names are case-insensitive (BPM, bpm, Bpm all work)
Tip
All commands on a line are executed together in sequence, with no delay between them. Use blank lines to create timing gaps.

03 Autoplay & Timing

When Autoplay is enabled in the Remote, lines execute automatically based on BPM and Beats.

Timing Formula

beat_interval = (60 / BPM) seconds
line_interval = beat_interval × BEATS

Example: BPM=120, BEATS=8
  beat = 60/120 = 0.5s
  line = 0.5 × 8 = 4.0 seconds between lines

Behavior

  • After the last line, autoplay wraps to the first line (unless STOP or random mode)
  • Blank lines consume one full line interval (delay)
  • Comment lines are skipped entirely (no delay)
  • The RAND toggle sends a random line each interval instead of sequential
  • BPM supports fractional values (e.g., BPM=98.5)
Note
The timer may drift over time depending on BPM, beats, and system performance. Use the RESET command to re-sync, or double-click the "BPM" label in the Remote window.

05 Messages & Text

Any text on a command line that isn't a recognized command is sent as a message to the visualizer, where it appears as an animated text overlay.

Hello World!
FONT=Courier New|This text uses Courier
COLOR=255,0,0|SIZE=40|Big red text!

How Messages Are Sent

When a plain message is sent, the Remote automatically appends the current UI settings:

  • font= — current font face
  • size= — current font size
  • r=, g=, b= — current color
  • The current style parameters (if a style is selected)

This means commands like FONT=, SIZE=, and COLOR= set the defaults that get applied to subsequent messages on the same or following lines.

Line Breaks

Use // within message text to create a line break:

First line//Second line

Auto-Wrap

If the Wrap option is enabled in the Remote, long messages are automatically split at the nearest word boundary using //.

Limit
Message text is truncated to 500 characters maximum.

06 MSG= Raw Command

The MSG= command sends a message with full control over every parameter. Parameters are separated by semicolons (;):

MSG=time=5.0;growth=1.5;text=This is the message

Unlike plain messages, MSG= bypasses the default style — only the font, size, and r/g/b defaults are appended if not specified in the parameters.

Animated Movement

Use startx/starty with movetime to animate text from one position to another:

# Slide in from upper-left to center
MSG=startx=0;starty=0;x=0.5;y=0.5;movetime=1.0;text=Hello!

# Slide in from right with easing
MSG=startx=1;starty=0.5;y=0.5;movetime=1.0;easemode=1;text=Eased in

Background Box

Messages can have a colored background box:

MSG=box_alpha=0.7;box_col=0,0,0;box_left=0.1;box_right=0.9;box_top=0.4;box_bottom=0.6;text=Boxed text

Supertext Slots
The visualizer supports up to 10 simultaneous text overlays. New messages are placed in the next free slot. If a new message targets the same x/y position as an existing non-animated message, the old one is ended early.

08 Styles

Styles are named parameter presets configured in the Remote's Style editor. They store a set of message parameters (position, timing, growth, animation, etc.) that get appended to every message sent while the style is active.

STYLE=Style A|This message uses Style A's parameters
STYLE=Style B|Now using Style B

Styles are matched by name (case-insensitive). If a style isn't found, a status message is shown. Styles are saved in the Remote's configuration.

Tip
Use styles to avoid repeating the same positioning/timing parameters. Set up styles like "Center Fade", "Bottom Slide", "Random Scatter" in the Remote, then reference them by name in your script.

09 Presets

Presets are .milk files that define the visualizer's rendering behavior. Use the PRESET= command to load a specific preset:

# Relative path (from Milkwave base directory)
PRESET=resources\presets\Milkwave\01 - Martin - blue haze.milk

# Absolute path
PRESET=C:\Presets\MyPreset.milk

# Combined with a message
PRESET=resources\presets\Milkwave\cool.milk|Check out this preset!

The visualizer will also update its internal preset index to match the loaded file, so NEXT/PREV will navigate relative to the loaded preset's position in the directory.

10 SEND & Sprites

The SEND= command sends characters or keycodes directly to the Visualizer window.

Sprite Triggering

Typing a two-digit number triggers the corresponding sprite (00–99):

SEND=00    # Trigger sprite 00
SEND=99    # Trigger sprite 99

Keycodes

Prefix with 0x to send a virtual keycode (hexadecimal):

SEND=0x73   # F4 key
SEND=0x20   # Space key

See Microsoft Virtual Key Codes for the full list.

Unicode Characters

Any other string is sent as Unicode characters to the Visualizer window:

SEND=abc   # Sends characters 'a', 'b', 'c'

11 Settings Commands

These commands modify the Remote's Settings tab values, which affect how the visualizer renders.

Speed & Frame Rate

  • TIME=n — Time factor multiplier (affects overall preset speed)
  • FRAME=n — Frame factor (affects per-frame progression)
  • FPS=n — FPS factor (affects target frame rate)

Visualization

  • INTENSITY=n — Controls vis_intensity shader variable
  • SHIFT=n — Controls vis_shift shader variable (can be negative)
  • VERSION=n — Controls vis_version shader variable (integer)
  • QUALITY=n — Render quality/pixelization level

Color Shifting

  • HUE=n — Shift the overall hue of the visualization
  • SATURATION=n — Shift saturation
  • BRIGHTNESS=n — Shift brightness

All values are floats clamped to the Remote's UI control range.

12 Examples

Basic Script

# Set up timing and initial style
BPM=120|BEATS=8|STYLE=Center Fade

# Each line plays every 4 seconds (120 BPM * 8 beats)
Welcome!
NEXT|New preset loaded
COLOR=255,200,0|Golden text
STOP

Animated Messages

# Text slides in from different directions
MSG=startx=0;starty=0;x=0.5;y=0.4;movetime=1.0;time=4.0;text=From top-left
MSG=startx=1;starty=0.5;x=0.5;y=0.5;movetime=1.0;easemode=1;text=From right

Preset Show with Timing Changes

BPM=120|BEATS=8
PRESET=resources\presets\Milkwave\cool.milk|Check this out
Getting faster...
BPM=180|BEATS=4|PRESET=resources\presets\Milkwave\intense.milk
RESET|SIZE=50|BOOM!

# Blank line = one interval of silence

SIZE=80|BIGGER BOOM!
STOP

MIDI-Friendly Script

# Lines designed for MIDI triggers (LINE=CURR/NEXT/PREV)
PRESET=resources\presets\chill.milk|INTENSITY=0.8|Chill mode
PRESET=resources\presets\hype.milk|INTENSITY=1.5|Hype!
CLEARSPRITES|CLEARTEXTS|Reset everything
HUE=-0.5|SATURATION=1.2|Color shift!

Background Box Text

MSG=text=Important announcement;size=40;time=8;box_alpha=0.6;box_col=0,0,0;box_left=0.15;box_right=0.85;box_top=0.42;box_bottom=0.58
